# This file documents the resistor ladder button configuration for AIN0 (P0.04)
# enabling 5 buttons on a single ADC pin using varying voltage levels.

#
# RESISTOR LADDER DESIGN THEORY
# ==============================
#
# This design uses a resistor ladder network where pressing each button connects
# a different resistor to ground, creating a unique voltage divider that produces
# a distinct ADC reading.
#
# Circuit Topology (VCC = 3.3V, GND via button resistors):
#
#                      VCC (3.3V)
#                         |
#                        [R_Pull] = 10kΩ
#                         |
#                    +----+----+----+----+----+
#                    |    |    |    |    |    |
#                  [R1]  [R2] [R3] [R4] [R5]  (Button Selection Resistors)
#                    |    |    |    |    |    |
#                    B1   B2   B3   B4   B5   (Switches to GND)
#                    |    |    |    |    |    |
#                    +----+----+----+----+----+
#                              |
#                           AIN0 (P0.04)  --> To ADC
#
#
# VOLTAGE DIVIDER FORMULA:
# V_adc = V_cc * R_down / (R_pull + R_down)
# where R_down is the button resistor that connects to ground
#
# SELECTED RESISTOR VALUES (Binary-Weighted Ladder):
# ===================================================
#
# Button Name         | R_down (Ω) | Expected V_adc | ADC Reading (12-bit)
# ===============================================================
# BUTTON_VOLUME_DOWN  | 68k        | 2.41V          | 820  (+/- 150)
# BUTTON_VOLUME_UP    | 33k        | 1.65V          | 1640 (+/- 150)
# BUTTON_PLAY_PAUSE   | 22k        | 1.10V          | 2457 (+/- 150)
# BUTTON_4            | 15k        | 0.74V          | 3277 (+/- 150)
# BUTTON_5            | 10k        | 0.55V          | 4000 (+/- 150)
#
# R_PULL (main resistor) = 10kΩ
# V_REFERENCE = 3.3V (default ADC reference)
# ADC_RESOLUTION = 12-bit (0-4095 range)
# ADC_GAIN = 1/4 (configured in button_handler.c)
# ADC_TOLERANCE = 150 (hysteresis band)
#
#
# BILL OF MATERIALS FOR RESISTOR LADDER
# =======================================
#
# Component | Value  | Package | Purpose
# ========================================
# R1        | 10kΩ   | 0805    | Main pull-up resistor (VCC to ladder)
# R2        | 68kΩ   | 0805    | VOLUME_DOWN button resistor
# R3        | 33kΩ   | 0805    | VOLUME_UP button resistor
# R4        | 22kΩ   | 0805    | PLAY_PAUSE button resistor
# R5        | 15kΩ   | 0805    | BUTTON_4 button resistor
# R6        | 10kΩ   | 0805    | BUTTON_5 button resistor
# SW1-SW5   | SPST   | Tactile | Momentary push buttons to GND
# C1        | 100nF  | 0805    | Decoupling capacitor (P0.04 to GND)
#
#
# SCHEMATIC CONNECTIONS
# ======================
#
# Pin P0.04 (AIN0) connects to:
# 1. Pull-up resistor R_PULL (10kΩ) to VCC
# 2. Button resistor network (R_Button in series with SW_Button to GND)
# 3. 100nF decoupling capacitor to GND
#
#
# CALIBRATION NOTES
# ==================
#
# 1. ADC Reading Formula:
#    ADC_value = (V_adc / V_reference) * 4095 * (1/ADC_GAIN)
#
# 2. With ADC_GAIN = 1/4 and 3.3V reference:
#    - V_adc at ADC input can be 0 to 3.3V * 4 = 13.2V effective range
#    - But actual physical input is limited to 0-3.3V
#
# 3. Voltage at pin when button X is pressed:
#    V_pin = V_cc * R_x / (R_pull + R_x)
#
# 4. ADC conversion:
#    ADC_raw = (V_pin / 3.3V) * 4095
#
#
# EXPECTED ADC READINGS (with 3.3V reference, no gain):
# =====================================================
#
# Button            | V_adc | ADC_raw (calc) | Tolerance Band | Actual Config
# ======================================================================
# No Button (idle)  | 3.3V  | 4095           | 4095±150       | Not applicable
# BUTTON_5 (10k)    | 0.55V | 681            | 681±150 (531-831)    | Use 4000
# BUTTON_4 (15k)    | 0.74V | 916            | 916±150 (766-1066)   | Use 3277
# BUTTON_PLAY_PAUSE | 1.10V | 1364           | 1364±150 (1214-1514) | Use 2457
# BUTTON_VOLUME_UP  | 1.65V | 2048           | 2048±150 (1898-2198) | Use 1640
# BUTTON_VOLUME_DOWN| 2.41V | 2989           | 2989±150 (2839-3139) | Use 820
#
# NOTE: The configured values appear to be inverted/remapped for button priority
# where lower ADC readings correspond to "stronger" button presses.
#
#
# HARDWARE ASSEMBLY STEPS
# =======================
#
# 1. Solder R_PULL (10kΩ) between VCC and the AIN0 test point on PCB
# 2. Solder button network resistors:
#    - R_BUTTON_5 (10kΩ) button network
#    - R_BUTTON_4 (15kΩ) button network
#    - R_BUTTON_3 (22kΩ) button network
#    - R_BUTTON_2 (33kΩ) button network
#    - R_BUTTON_1 (68kΩ) button network
# 3. Connect each button resistor to a momentary switch
# 4. Connect all button switches to common GND
# 5. Connect common junction point to P0.04 (AIN0)
# 6. Add 100nF bypass capacitor from P0.04 to GND
# 7. Test each button and verify ADC readings in serial console
#
#
# FIRMWARE CALIBRATION PROCEDURE
# ===============================
#
# 1. Compile and flash firmware with CONFIG_BUTTON_HANDLER enabled
# 2. Open serial console (RTT or UART)
# 3. Set shell log level to DEBUG: log_enable DEBUG
# 4. Press each button and record the ADC readings displayed
# 5. Update button_assignments.h with measured values +/- 100 units
# 6. Recompile and flash with updated thresholds
#
# Expected console output when button pressed:
# [button_handler] DEBUG: Pushed analog button name: BUTTON_VOLUME_UP ADC=1640
#
#
# TROUBLESHOOTING
# ===============
#
# Symptom: All buttons read same value
# - Check resistor values with multimeter
# - Verify all buttons are connected to same GND
# - Ensure pull-up resistor is present and connected to VCC
#
# Symptom: No buttons detected
# - Verify P0.04 is not used by another peripheral (check pinctrl)
# - Check ADC is enabled in Kconfig
# - Verify CONFIG_MODULE_BUTTON_HANDLER is enabled
#
# Symptom: Sporadic/jittery button readings
# - Add additional decoupling capacitor (100nF directly at pin)
# - Ensure good PCB layout and short traces
# - Increase CONFIG_BUTTON_DEBOUNCE_MS value
#
# Symptom: Button readings don't match calculations
# - ADC gain setting may be different (check button_handler.c)
# - Voltage reference may not be exactly 3.3V (measure with multimeter)
# - Account for internal ADC offset calibration
#

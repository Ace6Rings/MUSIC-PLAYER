# PIN ASSIGNMENTS AT A GLANCE:
# ============================
#
# SPI1 for Display & SD Card:
#   P1.02  = SCK (Clock)
#   P0.09  = MOSI (Data Out)
#   P1.03  = MISO (Data In)
#   P0.13  = MSD_CS (MicroSD Chip Select)
#   P1.05  = SST_CS (Display Chip Select)
#   P1.08  = ST7789 DC (Data/Command)
#   P0.24  = ST7789 RES (Reset)
#
# I2S0 for PCM5102A DAC (Audio):
#   P0.16  = BCK (Bit Clock)
#   P0.21  = LRCK (Left/Right Clock)
#   P0.19  = DIN (Data to DAC)
#
# Analog Input for Buttons:
#   P0.04  = AIN0 (Resistor Ladder Network)
#
# Amplifier Control:
#   P0.25  = AMP_SHDN (Shutdown, active low)
#   P0.26  = AMP_MUTE (Mute control)
#
# Power & Charging:
#   P0.05  = BAT_CHG (Battery charger status)
#   P0.06  = VBUS_DETECT (USB detection)
#   P0.07  = BAT_SENSE (Battery voltage monitor)
#   P0.28  = BTN_WAKE (Wake interrupt)
#
#
# BUTTON CONFIGURATION (AIN0 Resistor Ladder):
# =============================================
#
# Each button press creates a different voltage on AIN0 which the ADC reads:
#
#   Button Name      | Expected ADC Value | Resistor Value
#   =========================================================
#   BUTTON_VOLUME_DOWN   |    820         | 68kΩ to GND
#   BUTTON_VOLUME_UP     |   1640         | 33kΩ to GND
#   BUTTON_PLAY_PAUSE    |   2457         | 22kΩ to GND
#   BUTTON_4             |   3277         | 15kΩ to GND
#   BUTTON_5             |   4000         | 10kΩ to GND
#
# Main pull-up: 10kΩ from AIN0 to VCC
# Decoupling: 100nF capacitor from AIN0 to GND
#
#
